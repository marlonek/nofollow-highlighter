Test page – Nofollow Highlighter

Load the extension in chrome://extensions (Developer mode → "Load unpacked"), enable Allow access to file URLs in its details, then open this file. With highlighting enabled, links are marked automatically. Use the popup to toggle link types and switch styles A / B / C.

1. Dofollow (no rel) – expected 🟢 green

  • Plain link without rel
  • rel="noopener noreferrer" (still dofollow for SEO)

2. Nofollow – expected 🔴 red

  • rel="nofollow"
  • rel="nofollow noopener"

3. Sponsored – expected 🟠 orange

  • rel="sponsored"

4. UGC – expected 🔵 blue

  • rel="ugc"

5. Mixed (priority: sponsored → ugc → nofollow)

  • rel="sponsored nofollow" → 🟠 sponsored
  • rel="ugc nofollow" → 🔵 ugc
  • rel="nofollow ugc sponsored" → 🟠 sponsored

6. Internal vs external (hover for the tooltip)

  • Internal link (same domain)
  • External nofollow link

7. Links that should NOT be marked

  • Anchor #section
  • mailto:
  • tel:
  • javascript:
  • Link without href

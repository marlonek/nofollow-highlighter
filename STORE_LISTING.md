## Detailed description

Nofollow Highlighter instantly shows how every link on a page is treated for SEO,
based on its rel attribute — so you can audit internal and outbound links at a glance.

Each link is color-coded by type:

• dofollow (green) — passes link equity
• nofollow (red) — does not pass equity
• sponsored (orange) — paid / advertising link
• ugc (blue) — user-generated content (comments, forums)

Links with several rel values (e.g. rel="sponsored nofollow") are classified by
priority: sponsored → ugc → nofollow. Hover any link to see its full rel value and
whether it points to an internal or external domain.

KEY FEATURES

• Automatic highlighting on the pages you visit — no clicking required
• Toolbar badge with the number of non-dofollow links on the current page
• Choose which link types to highlight (e.g. only nofollow, or nofollow + ugc)
• "External links only" mode for outbound-link audits
• Three marking styles: underline, badge, or both
• Global on/off switch and a per-site toggle (exclude specific domains)
• Live updates — changes apply instantly, no page reload needed
• Works with dynamically loaded content (infinite scroll, single-page apps)

PRIVACY FIRST

This extension runs 100% locally. It only reads the page you are on to color its links.
It makes no network requests, collects no data, uses no tracking, and loads no remote
code. Nothing ever leaves your browser.

Only http/https links are marked; anchors (#), mailto:, tel: and javascript: links are
skipped.

Perfect for SEO specialists, content editors, link builders and webmasters who need a
quick, trustworthy view of a page's link profile.

## Single purpose (required)
Highlight links on web pages according to their rel attribute (nofollow, sponsored, ugc,
dofollow) to help with SEO review.

## Permission justifications

storage
Saves your settings locally in the browser (on/off state, marking style, which link
types to show, external-only mode, and the list of sites you excluded). No settings are
sent anywhere.

Host permissions (http://*/* and https://*/*)
Required so the extension can read the links on the pages you open and color them in
place. The extension only reads the DOM to classify links; it does not transmit, store
remotely, or share any page content or browsing data.
